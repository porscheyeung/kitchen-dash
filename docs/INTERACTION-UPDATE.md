# 互動升級設計

日期：2026-10-29

參考版本：Git 提交 f0651de（原 V2，單頁 index.html），與 ffcd189（十關響應式版本）。

原 V2 透過食材直接手勢、火候及多士焦色、自由拖放提供參與感。十關版本保留進度與點選替代操作，但煎蛋只需等待、自由擺盤變成固定位置配對。本次在既有十關基礎加入：

1. 雞蛋隨手勢移動，達到有效下滑距離時顯示閃電；取消手勢會復位，忽略第二隻手指。
2. 攪拌增加按住控制，依真實經過時間累積；仍支援畫圈及逐圈按鈕。暫停清除按住狀態。
3. 半熟翻面成為必要操作。熟度暫停在 50%，熱力與關卡時間仍繼續；翻面後才可煎熟另一面。每步仍最高 20 分。
4. 小／中／大火提供大面積觸控目標，滑桿保留精細調節。鍋邊高亮表示目前火候合適。
5. 配對擺盤保留。自由模式可在碟內點選放下、拖放、方向鍵微調及 Enter／空白鍵放下；已放妥的食物可再次移動，無效拖放回到有效位置。位置相對碟中央儲存在單局狀態，旋轉後重排，並顯示於結算。
6. 手機主要操作按鈕全寬，標題／暫停置頂，觸控區與可捲動頁面分開；iPad 範圍改用完整寬度操作區，訂單與時間列在下面。

保留 kitchen-dash-v3、原有最佳分數、逐關解鎖、計分上限、失敗重試及分頁切換暫停。沒有加入測試解鎖後門、外部執行期依賴或資料上傳。

驗證方法及限制見 TEST-RESULTS.md；手機、iPad 為 Chromium 觸控與 viewport 模擬，未以實體裝置或 Safari 驗證。
