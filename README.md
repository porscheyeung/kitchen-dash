# Kitchen Dash · 小廚師日記

零執行期依賴的繁體中文料理遊戲，可直接部署 GitHub Pages。原版的一輪五步驟，升級為 10 關漸進式挑戰；保留打蛋、畫圓攪拌、調火煎蛋、多士彈出、自由拖放擺盤的核心，新增對應位置與點選操作。

## 遊玩

每步先閱讀提示，再開始計時。每步最高 20 分，總分 100；55 分過關、72 分兩星、90 分三星。通關逐一解鎖下一關，失敗可立即重試。最佳成績與解鎖進度只存於目前瀏覽器；無帳號或資料上傳。音效預設關閉。切換分頁自動暫停，Escape 也可暫停。

每關多士速度同步提高，拖放容許偏差逐步減小；點選配對保留給觸控、鍵盤及不方便拖動的玩家。關卡使用相同五種料理操作與不同挑戰設定，不是十種獨立食譜模擬。

## 檔案與測試

- `index.html`：入口與暫停對話框。
- `styles.css`：響應式介面，無外部字型或圖片請求。
- `game.js`：關卡、狀態、指標操作、烹調、存檔。
- `tests/game.spec.js`：瀏覽器流程、手勢、存檔、暫停、逾時及版面檢查。

本機預覽：`npm start`。首次測試：`npm ci`、`npx playwright install chromium`、`npm test`。測試會自行啟動本機靜態伺服器。實際測試結果見 `docs/TEST-RESULTS.md`。

GitHub Pages 現有發布來源為 `main` 根目錄；功能分支推送不會改變正式頁面。保留此發布設定，合併後才更新正式版。
